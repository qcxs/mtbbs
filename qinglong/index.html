青龙面板脚本 ​

MT 论坛青龙自动签到助手，支持多账号自动签到、概率签到、Cookie 缓存、消息提醒、异常通知。

WARNING

为防止脚本大量使用对论坛造成影响，没有发帖，也没有声张，不建议在公开场合讨论。

功能亮点 ​

  • 多账号支持：一次配置，批量自动签到
  • 智能概率签到：自定义时间段内概率递增签到，避免固定时间打卡风控
  • 自动缓存 Cookie：首次登录缓存 Cookie，之后复用
  • 论坛新消息提醒：自动检测未读消息并推送
  • 自定义通知时间：仅在指定时段发送通知
  • 异常自动处理：Cookie 过期自动清空，下次运行重新登录
  • 完整日志记录：执行状态一目了然

环境变量配置 ​

青龙面板 → 环境变量 → 新建变量，必填 1 个，选填 2 个。

1. 必选：账号配置（mtbbs_accounts） ​

格式为 JSON 数组，支持多账号：

json
[
  {"username":"账号1","password":"密码1"},
  {"username":"账号2","password":"密码2"}
]

2. 可选：消息提醒时间段（mtbbs_message_time） ​

仅在该时段发送青龙通知，格式：开始小时-结束小时，多时段用逗号分隔。

8-12,18-22
  • 示例：9-21 代表每天 9 点 ~ 21 点才发送通知
  • 不配置则全天不发送通知，只挂机

3. 可选：概率签到时间段（mtbbs_sign_time） ​

在该时段内概率递增签到，格式同上。

0-23
  • 概率规则：越接近结束时间，签到概率越高
  • 不配置则不自动签到
  • 配置 0-23 为全天概率签到

快速部署 ​

  1. 青龙面板 → 脚本管理 → 新建脚本（如 mt_bbs.py）
  2. 粘贴 qcxs_mtbbs.py 完整代码并保存
  3. 配置环境变量（至少配置账号变量）
  4. 添加定时任务：命令填 task mt_bbs.py，建议定时 0 8-22/2 * * *

定时建议 ​

  • 执行频率：每 2 小时运行一次
  • 推荐定时：0 8,20,32,44,56 * * * ?（始终保持在线）

常见问题 ​

提示登录失败 ​

  • 检查账号密码是否正确
  • 确认 MT 论坛账号无异常
  • 不支持验证码、安全提问

频繁提示 Cookie 过期 ​

  • 手动登录论坛后，删除缓存文件或清空环境变量重新登录
  • 尽量不要在多处同时使用相同账号签到

不发送通知 ​

  • 检查是否配置 mtbbs_message_time 变量
  • 确认当前时间在通知时段内
  • 检查青龙通知渠道是否正常

文件说明 ​

  • 脚本文件：qinglong/qcxs_mtbbs.py
  • 运行后自动创建 cache 目录，存储账号 Cookie 与签到记录
