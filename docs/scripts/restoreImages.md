# 图片恢复

# 帖子

[【MT论坛】移动端图片恢复功能](https://bbs.binmt.cc/thread-166955-1-1.html)

# 使用教程

功能类似于PC端图片恢复
![attachments/Pasted image 20260525112517.png](/images/restoreImages/Pasted%20image%2020260525112517.png)
安装后自动检测，并提示
![attachments/Pasted image 20260525112347.png](/images/restoreImages/Pasted%20image%2020260525112347.png)
点击使用
![attachments/Pasted image 20260525112450.png](/images/restoreImages/Pasted%20image%2020260525112450.png)
正常插入图片（恢复的图片在"加号"前，上传的图片在后）

如果想删除图片，避免频繁提示，请先点击"使用"，再手动删除。

注意：脚本仅恢复图片，输入的内容不回复，可搭配[【移动端】MT论坛优化 | ScriptCat](https://scriptcat.org/zh-CN/script-show-page/2524)使用，它有恢复帖子输入，但没有恢复图片功能。或者你自己用ai加这个功能。
