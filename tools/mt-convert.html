MT Convert 转换器 ​

Markdown / BBCode / HTML 在线互转工具。

功能 ​

  • BBCode → HTML: 将论坛 BBCode 转换为标准 HTML
  • Markdown → BBCode: 将 Markdown 格式转换为论坛 BBCode

在线使用 ​

直接访问 qcxs.github.io/mtbbs/mt-convert/ 即可使用。

技术栈 ​

  • Vue 3 + TypeScript
  • Element Plus
  • Vite

相关资源 ​

  • BBCode 与 HTML 对应关系
  • require/ — BBCode/HTML 互转核心库
