# mtbbs

MT论坛 移动端适配脚本与工具集合。

- 网站导航：[qcxs.github.io/mtbbs](https://qcxs.github.io/mtbbs/)
- MT Convert：[qcxs.github.io/mtbbs/mt-convert/](https://qcxs.github.io/mtbbs/mt-convert/)

## 文档

各脚本的使用说明和详细介绍请访问 [项目文档](https://qcxs.github.io/mtbbs/)。

## 脚本安装

通过 [ScriptCat](https://scriptcat.org/zh-CN/users/202514) 安装，或在仓库中找到 `*.user.js` 文件点击 Raw 安装。
