mtbbs — MT论坛 移动端适配脚本与工具 ​

这里是 qcxs/mtbbs，存储了自用适配 MT 论坛 移动端的脚本、网站。

初始只是个人为 Alook 浏览器 编写一些脚本，存放在 123 盘中。经历了不断优化，有三种脚本成功入围 编程开发 - MT论坛 精华帖，现将脚本源码统一整理，存储在此仓库中，随缘更新。

PS：由于Alook佛系更新，转至雨见浏览器，支持插件，故新脚本不再是纯js，开始拥抱油猴API。

脚本使用方法 ​

通过脚本猫安装（推荐） ​

qcxs - 用户主页 | ScriptCat

不一定将所有脚本都发布在脚本猫中，但最新脚本在此更新。

通过 GitHub 安装 ​

核心脚本总在更新，此处不再提供最新代码

在仓库中找到以 user.js 结尾的文件，它就是脚本。

点击 Raw，油猴自动识别。

使用 CDN 加速 ​

由于国内访问 GitHub 时好时坏，可以通过 jsDelivr 进行 CDN 加速。

https://cdn.jsdelivr.net/gh/qcxs/mtbbs/

不过由于缓存，需等待一段时间才能获取到最新版本。

从 URL 安装 ​

脚本已重命名为 user.js 后缀，正常情况下，油猴会自动识别安装，也可自行输入 URL 安装。

网站 ​

仓库开启了 GitHub Pages，可通过 qcxs.github.io/mtbbs 访问。
